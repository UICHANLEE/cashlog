# Cashlog 최종 CRO·접근성 점검

점검일: 2026-08-10

기준: `origin/main`에서 분기한 `codex/first-session-cro`

원칙: 사용자 데이터 생성·수정 없이 로컬 빌드와 빈 상태만 검증

## 한 줄 결론

첫 방문에서 제품 가치와 캐릭터 성장 이유가 바로 보이고, 촬영 CTA 하나로 시작할 수 있게 됐다. 첨부 감사의 P0 중 약관, 가입 경로, 스토리 잠금 설명, 공유 미리보기는 코드와 빌드에 반영됐다.

## 반영한 수정

- 첫 방문 가치 제안, 가입 없이 시작, 캐릭터 성장 이유, 사진·위치 보호 문구 추가
- 중복 촬영 진입점을 하나의 주 CTA와 앨범·직접 입력 보조 경로로 정리
- 하루·한 달 스토리 비활성 사유를 화면·`aria-describedby`·`title`로 제공
- 앱 내부 및 전용 가입 화면에 이용약관 동의 추가, 필수 전체 동의 제공
- 전용 가입 화면에 Google·카카오 노출, 프로필 사진을 선택 항목으로 후순위 이동
- 입력 `name`·`autocomplete` 보강, 프로필 로딩을 스켈레톤으로 교체
- OG/Twitter 메타, manifest, Apple 아이콘, 앱 아이콘, robots, sitemap 추가
- 공개 GitHub 링크를 제거하고 개인정보·약관 링크로 교체
- 타임라인 이미지를 지연 로딩하고 하단 안전 영역을 보강

## 운영 확인 필요

- `privacy@cashlog.ai.kr`가 실제 수신되도록 메일 라우팅을 연결해야 한다.
- Google·카카오 Provider와 프로덕션 Redirect URL은 배포 환경에서 실제 로그인으로 한 번씩 확인해야 한다.
- 프로필 API와 Supabase 서명 URL의 실제 7초 지연은 스켈레톤으로 체감만 완화했다. 썸네일 생성, 서명 URL 캐시·배치 발급은 별도 성능 작업이 필요하다.
- 실제 카메라 권한, 사진 업로드·AI 분석, iOS 홈 화면 추가는 데이터 생성과 기기 권한이 필요해 이번 무데이터 점검 범위에서 제외했다.
- 루트는 앱이라는 제품 결정을 유지했다. `noscript` 설명은 추가했지만 완전한 SSR·프리렌더링은 별도 검색 최적화 작업이다.
